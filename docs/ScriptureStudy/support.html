Getting Started

Which computers does ScriptureStudy run on?
ScriptureStudy Pro™ runs on the Mac (macOS 15 Sequoia or later) and on Windows (Windows 11, or Windows 10 version 1809 or later, on Intel, AMD or Arm PCs). The Mac version comes from the Mac App Store and the Windows version from the Microsoft Store. Each is bought separately, and your notes and settings stay on the computer you use.
The app opens but shows no Bible text. What do I do?
The app comes with a set of built-in modules, including a Bible. Open the Modules tab and make sure a Bible is chosen — click its heart. To add more, use Online Catalogue to download modules, Cloud Library to copy in your own, or My Modules to read a folder of modules where it is.
Where do I get more Bible modules?
The Online Catalogue in the Modules tab lists modules you can download directly. ScriptureStudy also reads MyBible-format modules, and free ones for hundreds of languages are available at mybible.zone: download them to a folder on your computer, then add them with Cloud Library or My Modules.
What module format does ScriptureStudy use?
ScriptureStudy reads its own .graphe modules and MyBible-format SQLite modules (.SQLite3 and .mybible).
How do I set up the AI features?
The brIΛn tab in the Companion Panel and the chapter summaries use an AI provider. In Settings → brIΛn, add your own API key for Anthropic (Claude), OpenAI or Google (Gemini); on a Mac with Apple Intelligence you can also use Apple's on-device model. On Windows, brIΛn and the chapter summaries use the providers and keys you add. All AI features are entirely optional — the app is fully functional without them.

Common Questions

My notes aren't appearing on my other Mac. What's wrong?
On the Mac, notes sync via iCloud Drive. Make sure iCloud Drive is enabled in System Settings → Apple ID → iCloud and that ScriptureStudy has iCloud access. Sync can take a minute or two after a change. If notes are still missing, check that both Macs are signed into the same Apple ID.
Do my notes sync between my PCs, or between Windows and the Mac?
No. The Windows version keeps your notes, bookmarks and settings on the PC you use it on. To move notes, use Export All Notes in the Notes tab and Import Notes on the other computer.
Where does the Windows version keep my data?
In your user profile, in %LOCALAPPDATA%\Studio Graphē One\ScriptureStudy Pro: your notes, settings, the modules you add and the search index. API keys are kept in Windows Credential Manager.
My maps aren't showing images. What's wrong?
Make sure a Bible Maps (BMaps) module is in your library — it is one of the built-in modules. If it is there, open the Modules tab and refresh the library to scan it again.
I changed my modules folder on the Mac and now nothing loads.
Go to the Modules tab and choose the folder again to re-grant access. macOS security requires you to reconfirm folder access after certain changes.
A module appears in the wrong category in the library.
Module type is detected from the database structure. If a module is miscategorised, its internal description field may be misleading the detector. You can correct it using a SQLite editor such as DB Browser for SQLite, or contact the module author for an updated version.
