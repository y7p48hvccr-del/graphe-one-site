Supported File Formats

What module files ScriptureStudy can read

Native format — MyBible SQLite

ScriptureStudy reads MyBible-format SQLite files directly. These are standard SQLite3 databases with a .SQLite3 extension. The module type is detected automatically from the tables present:

TableModule type
versesBible
devotionsDevotional
reading_planReading Plan
cross_referencesCross-Reference (OBX)
commentaries + TSK/footnote flagCross-Reference (TSK)
commentariesCommentary
dictionary + is_strong=trueLexicon
dictionary + is_strong=falseDictionary

Imported formats — e-Sword / MySword

Use the standard import actions in the Library toolbar to bring readable SQLite-based e-Sword and MySword files into ScriptureStudy. Supported source extensions include .bbl, .bblx, .cmtx, .dctx, .lexdbtx, .devx, .topx, .refx, and .mybible. ScriptureStudy converts these files into its .graphe format and installs them into the app-managed library automatically.

Advanced users can enable Settings → Advanced Users → Show advanced library tools to reveal a Convert Only… action that writes a converted .graphe file to a folder they choose without installing it.

Note: Encrypted or otherwise unreadable commercial e-Sword files cannot be converted and will show an error.
